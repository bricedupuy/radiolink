# RadioLink

Professional P2P remote radio recording studio.

## Credits

RadioLink is inspired by and uses concepts from [VDO.Ninja](https://github.com/steveseguin/vdo.ninja) by Steve Seguin.

The WebRTC peer connection architecture is based on VDO.Ninja's approach, 
but completely rewritten for radio/podcast recording use cases.
